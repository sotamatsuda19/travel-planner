# Tokyo Trip Planner 地図×AI

会話しながら東京のおでかけプランを組み立てる Web アプリ。

🔗 **https://travel-planner-77n4.onrender.com**

---

## 何ができるか

- 会話でスポットを探し、旅程を組み立てられる（東京都内 70,087 スポット）
- **バリアフリー条件で絞り込める** — 車椅子で入れる / 段差なし / 多目的トイレ / おむつ替え台 /
  授乳室 / 点字ブロック / 手話・筆談対応 / 車椅子・ベビーカーの貸出 など19条件
- **食事制限で絞り込める** — ハラール / ベジタリアン / アレルギー対応
- ユーザーの意向に沿って柔軟に経路を表示できる（徒歩・電車・タクシー・車）
- 現在地・時刻・天気（気象庁）を基に、「今から」「雨だけど」に対応可能

---

## 仕組み

話しかけると、Claude が「何を調べればいいか」を自分で判断して、下の3つのツールを呼び出す。

| ツール | 中身 |
|---|---|
| `search_places` | ローカル全文検索。距離・営業中判定・説明文・バリアフリー条件での絞り込み |
| `get_route` | OSRM + 自前の鉄道グラフ + 運賃 + 累積標高 |
| `save_itinerary` | プランの確定。区間ごとの経路・所要時間・到着予定時刻を計算 |

バックエンドは手元のオープンデータや外部サービスから答えを作り、それを**2か所へ同時に流す**。

```
        あなたの発話
             ↓
   Claude がツールを選択
             ↓
   バックエンドが実行
   （オープンデータ + 外部API）
             ↓
      ┌──────────────┐
      ↓              ↓
  Claude が        地図にピンと
  文章で答える      経路が出る
```

だから「返事の文章」と「地図の変化」が同時に起きる。
地図の操作もモデルには任せず、検索結果や経路の範囲に自動で合わせている。

## 技術スタック

| 領域 | 使ったもの |
|---|---|
| LLM | Claude Opus 5（tool use / streaming / prompt caching） |
| フロント | Next.js / React / TypeScript |
| 地図 | MapLibre GL JS + OpenFreeMap（ベクタタイル） |
| 経路 | OSRM（徒歩・車）+ 自前の鉄道グラフ（国土数値情報） |
| 検索 | 自前インデックス（7万件を全文スキャン） |
| 永続化 | Supabase（Postgres / JSONB） |

### 主なデータソース

| データ | 提供元 | 使いどころ |
|---|---|---|
| だれでも東京 | 東京都デジタルサービス局 | バリアフリー情報の本体（段差の高さcm・入口幅cmまである） |
| 飲食店バリアフリー情報 | 東京都産業労働局 | 設備 + ハラール・ベジタリアン・アレルギー対応 |
| 宿泊施設（旅館台帳） | 12区 | 旅館業法の許可台帳。簡易宿所を区別できる |
| 位置参照情報 | 国土交通省 | 住所しかない表の座標化 |
| 国土数値情報 N02 | 国土交通省 | 鉄道の線形・駅間距離 |
| 標高API | 国土地理院 | 徒歩ルートの累積標高 |
| 予報API | 気象庁 | 屋内/屋外プランの出し分け |
| OpenStreetMap | OSM contributors | POI 本体 |
| Wikidata / Wikivoyage | — | スポットの説明文 |
